Experience

Parasail · Performance Engineer

Feb 2026 – present

LLM inference provider serving open-weight models on large H200 / B200 / B300 GPU fleets

  • Cold start: cut engine startup with fastsafetensors + O_DIRECT + io_uring loading and vLLM GPU/CPU snapshot-restore (cuda-checkpoint + CRIU, up to 20× faster startup), plus the InstantTensor loader across vLLM and SGLang (1.5–4.3×). Traced a 293 s → 907 s startup regression to a stale FlashInfer autotuning cache. Blog posts: Making Cold Start Latencies go Brrrr, Restoring vLLM from Snapshots.
  • KV-cache offloading: took LMCache CPU-memory KV offloading in vLLM to production for a trillion-parameter MLA model, giving a 15× larger prefix-cache pool than GPU memory alone. Extended it to hybrid attention/Mamba models and fixed an MLA KV reload corruption bug.
  • Multi-tenant GPU serving: built the production layer for kvcached elastic KV-cache GPU sharing, including a Kubernetes device plugin, a node agent, and weight-aware and margin-aware placement. Served 16 models on 5 shared hosts.
  • Measurement: built a prefix-cache tracing pipeline to measure cross-request reuse, used to size GPU and CPU cache tiers and to rank which models to enable offloading for.
  • Open source: contributed upstream to LMCache and InstantTensor; maintain patches to vLLM, SGLang and kvcached.
