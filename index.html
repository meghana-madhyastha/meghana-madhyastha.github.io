LLM inference work at Parasail

cold start

Model cold-start and loading

Cut LLM engine startup time across the fleet. Combined fastsafetensors, O_DIRECT and io_uring so cold and warm starts are both fast on the same stack, and restored vLLM replicas from GPU and CPU snapshots (cuda-checkpoint and CRIU) instead of starting cold, which made startup up to 20× faster. Also rolled out the InstantTensor loader across vLLM and SGLang (1.5–4.3× faster loading) and traced a 293 s → 907 s startup regression to a stale FlashInfer autotuning cache.

Blog: Making Cold Start Latencies go Brrrr (Part 1) · Faster autoscaling for vLLM: restoring from snapshots

kv cache · offload

Tiered KV-cache offloading with LMCache

Took CPU-memory KV-cache offloading in vLLM to production for a trillion-parameter MLA model and for hybrid attention/Mamba models. The offload tier gives a 15× larger prefix-cache pool than GPU memory alone. Found and fixed a KV reload corruption bug for MLA layouts, and built a prefix-cache tracing pipeline to measure reuse and size each cache tier.

gpu sharing

Multi-tenant LLM serving with elastic KV cache

Built the production layer for kvcached-based GPU sharing, so many models share one GPU host with virtualized, elastic KV-cache memory. This included a Kubernetes device plugin and node agent, plus weight-aware and margin-aware placement. Packed 16 models onto 5 shared hosts in production.

open source

Open-source contributions

Contributed upstream to LMCache and InstantTensor. Also maintain patches to vLLM, SGLang and kvcached, including prefix caching for hybrid models, KV layouts for MLA, and loader and startup fixes.
